# Screen flows

## Dashboard

1. User searches for an asset from the left command bar.
2. User opens the asset detail view in the center workspace.
3. User pins the asset to favorites or adds it to a watchlist.

## Alert creation

1. User selects an asset.
2. User opens the alerts panel on the right rail.
3. User chooses condition, threshold and optional pattern target.
4. Triggered alerts are logged into history and notification center.

## Pattern-driven workflow

1. User selects pattern notification preferences.
2. The detection service scans incoming candles.
3. Confirmed patterns are marked on the chart and pushed to notifications.
